#STAR

**Situation**:
I am a QA engineer preparing to test the login page at https://app.vwo.com/. For this exercise, assume the approved requirements are below. 

- Registered users can log in with valid credentials. 
-Invalid credentials must not grant access and must give an error. 
-Email and password are mandatory. 
-Successful login opens the authenticated dashboard. 
-Invalid login gives an error message: "Inward, your email, password. IP address or location did not match." 

**Task**:
Create a functional test plan for the login module. Use the template here - Chepter_03_Prompt_Engineering\test-plan-template.md

**Action**:
- Define the objectives, scope, and testing approach.
- Cover valid login, invalid credentials, empty fields, and access to the dashboard after logging.
- Include positive, negative, and boundary scenarios where the supplied requirement supports them.
- Define test environment needs, test data, entry criteria, exit criteria, and deliverable.
- Mark unspecified behavior as it "Requires clarification". Do not invent password rules, exact error message, or session timeouts.

**Result**:
Return a test plan containing the below:
- Test plan ID and title
- Objective
- In scope and out of scope
- Test approach
- Test scenarios
- Environment and test data
- Entry and exit criteria
- Deliverables
- Raise open questions. 
- Use clear language and tables where useful. Label any proposed criteria as recommendations.
